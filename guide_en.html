Step 1: Cam/Screen Recording

Record webcam and screen simultaneously to collect UX research data.

1-1. Connect Webcam (Face View)

  • Click the "Reconnect" button.
  • Allow camera/microphone access in the browser.
  • On success, the status badge turns green "Connected".
  • The audio level meter (🎤) activates to show mic input.

1-2. Connect Screen (Screen View)

  • Click the "Reconnect" button.
  • Select the screen to share (Entire Screen / Window / Tab).
  • ⚠️ Make sure to check "Share system audio"! Without it, device sound will not be recorded.
  • On success, the status badge turns green "Connected".

1-3. Start and Stop Recording

  • "● Start Record" button starts recording and the timer begins.
  • During recording, the status badge changes to red "● Recording".
  • "■ Stop Record" button stops the recording.
  • Recording files are automatically downloaded: record_face_DATE_TIME.webm, record_screen_DATE_TIME.webm

1-4. Check Progress Log

  • Check the "📋 Progress Log" panel at the bottom for real-time action history.

Step 2: Eye Tracking Analysis

Track gaze from recorded videos using MediaPipe and generate result videos.

2-1. Load Videos

  • Click the Face View area (📂) to select the Face recording file.
  • Click the Screen / Game View area (📂) to select the Screen recording file.
  • Supported formats: MP4, WebM

2-2. Configure Analysis Options

  • Filename: Set the output filename.
  • Optimize (default): Default parameters are applied automatically. Sufficient for most cases.
  • Fine-Tune: Manually adjust parameters (sensitivity, Y-axis baseline, X-axis scale, etc.).

2-3. Sampling and Analysis

  • "🔍 Sampling (10%)": Quickly analyze 10% of the video for preview.
  • "👓 Start Analysis": Start full gaze tracking analysis.
  • "🛑 Stop Analysis": Stop the ongoing analysis.
  • When analysis is complete, the result video is automatically downloaded.
🗂️

Step 3: Multi Viewer

Synchronize Face View and Screen View for integrated analysis.

3-1. Load Videos

  • Click "📁 Open" on each card to select video files.
  • Load videos separately for Face View and Screen View.

3-2. Synchronized Playback

  • "▶ Play" button plays/pauses all videos simultaneously.
  • Master timeline slider synchronizes playback position across all videos.
  • "🔄 Reset" button resets all videos to initial state.

3-3. Layout and Widget Management

  • "🔄 Toggle Layout": Switch between vertical/horizontal layout.
  • Screen Height slider adjusts card height.
  • Drag the ⋮⋮ handle on card headers to reorder.
  • 🗑️ icon removes unnecessary widgets.

💡 Tips & FAQ

Recommended Browser

Best performance on latest PC Chrome. Chrome 94+ with WebCodecs API support is recommended.

Recording Format

Saved in WebM format (VP9 codec). Convert to MP4 using external tools if needed.

System Audio Issue

If "Share system audio" option is not visible, select "Entire Screen" or "Chrome Tab".

Fine-Tune Recommended Values

Default optimization mode is sufficient for most cases. Use fine-tuning only when results are inaccurate.
